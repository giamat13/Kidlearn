# KidLearn 🎈

אוסף משחקים ומשאבים חינוכיים לילדים, בעברית ובאנגלית. כל משחק הוא דף HTML עצמאי, ואין צורך בהתקנה.

## הרצה מקומית

1. שכפלו את המאגר: `git clone https://github.com/giamat13/Kidlearn.git`
2. פתחו את `index.html` בדפדפן.

המאגר הוא אתר סטטי בלבד. אין שלב build ואין צורך ב-`npm install`.

## מבנה המאגר

| נתיב | תיאור |
|---|---|
| `index.html` | דף הבית: מציג את הקטגוריות והמשחקים |
| `games.json` | רשימת הקטגוריות והפריטים. כל משחק חדש מתווסף כאן |
| `shared/` | קוד משותף: ארנק "כסף Kidlearn", ענן (שמירה לחשבון), ווידג'ט, הגדרות Firebase ו-EmailJS |
| `effects/` | צלילי אפקט, גופנים וקובץ `gamepad-ui.js` |
| `learn/` | אפליקציות לימוד: דקדוק, אוצר מילים, חידון וכו' |
| `<שם-משחק>/` | כל משחק נמצא בתיקייה משלו עם `index.html` |
| `firestore.rules`, `firebase.json` | כללי אבטחה ל-Firestore |
| `test/` | עותק שמתעדכן אוטומטית מכל branch שאינו `main` (ראו למטה) |

## המשחקים

- **עברית:** משחק האותיות, למידת איות, משחק הניקוד, המקרר הקסום
- **אנגלית:** Grammar Rules, Vocabulary, Quiz Time, משחק זיכרון אנגלית-עברית
- **חשבון:** למידת מספרים, לוח הכפל, חיבור וחיסור, הרפתקת החשבון, צביעה לפי מספרים
- **ידע כללי ומדעים:** עובדות, מדעים לכיתות א׳-י״ב (משחק חיצוני)
- **משחקים ויצירה:** משחק הזיכרון, דפי צביעה להדפסה, עיצוב סרגל מתקפל, הקריאה הראשונה שלי
- **עולם אמיתי:** מזג האוויר והירח, מצלמת חיות חיה
- **משפחה:** מכתב למשפחה (שליחת מייל דרך EmailJS)

## ארנק "כסף Kidlearn"

משחקים רבים מזכים את הילד במטבעות משותפים דרך `shared/kidlearn-wallet.js`.

- הארנק עובד גם בלי חשבון, ונשמר ב-`localStorage` של הדפדפן.
- כשהילד מחובר לחשבון, היתרה מסתנכרנת דרך הענן.
- לשימוש במשחק חדש: הוסיפו `<script src="../shared/kidlearn-wallet.js"></script>` ו-`KidLearnWallet.earn(...)`. ערכי התגמול מוגדרים ב-`REWARDS` בקובץ.

## הוספת משחק חדש

1. צרו תיקייה חדשה עם `index.html` בשורש המאגר.
2. הוסיפו פריט ל-`items` ב-`games.json` עם `id`, `title`, `description`, `icon`, `url` ו-`categories` (לפי `id` של הקטגוריה).
3. אם המשחק מזכה בכסף, השתמשו בארנק המשותף (ראו למעלה).

## Firebase ו-EmailJS (אופציונלי)

- `shared/kidlearn-firebase-config.js` מכיל את הגדרות הפרויקט של Firebase. המפתחות ציבוריים, והגנה אמיתית נמצאת ב-`firestore.rules`.
- `shared/kidlearn-emailjs-config.js` מכיל את מזהי EmailJS לשליחת מיילים מדף "מכתב למשפחה". תבנית המייל נמצאת ב-`family-mail/kidlearn-emailjs-template.html`.
- בלי הגדרות אלה, המשחקים עובדים, אבל שמירה לענן ושליחת מיילים לא יפעלו.

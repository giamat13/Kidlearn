# 🍎 המקרר החכם - אפליקציה חינוכית לילדים

אפליקציה אינטראקטיבית המלמדת ילדים על תזונה בריאה באמצעות מקרר וירטואלי.

## 🎯 מה השתנה?

**עדכון מבנה הפרויקט** - כל התיאורים והמידע על המזון נמצאים כעת בתיקיית `food/`!

### לפני העדכון:
- כל התיאורים היו כתובים בקובץ `app.js`
- שינוי תיאור דרש עריכה של קוד JavaScript
- קשה היה למצוא ולערוך תוכן ספציפי

### אחרי העדכון:
- ✅ **כל התיאורים בקבצי JSON בתיקיית `food/`**
- ✅ `app.js` מכיל רק קוד לוגי - אין בו תיאורים
- ✅ קל לערוך תיאורים ללא ידע בתכנות
- ✅ ניתן להוסיף מזונות חדשים בקלות

## 📁 מבנה הפרויקט

```
fridge-project/
├── index.html          # דף ה-HTML הראשי
├── style.css           # עיצוב ואנימציות
├── app.js             # קוד JavaScript (רק לוגיקה!)
└── food/              # כל המידע על המזון נמצא כאן! ⭐
    ├── vegetables.json   # ירקות וסלטים
    ├── fruits.json       # פירות
    ├── proteins.json     # חלבונים ומוצרי חלב
    ├── fast-food.json    # מזון מהיר
    └── snacks.json       # חטיפים ומתוקים
```

## ✏️ איך לערוך תיאורים?

### דוגמה - הוספת מזון חדש לקובץ vegetables.json:

```json
[
  {
    "icon": "🥦",
    "name": "ברוקולי",
    "type": "positive",
    "title": "✓ למה ברוקולי טוב לי?",
    "description": "גורם לך להיות חזק! עוזר למערכת החיסון..."
  },
  {
    "icon": "🍅",
    "name": "עגבנייה",
    "type": "positive",
    "title": "✓ למה עגבנייה טובה לי?",
    "description": "מלאה בוויטמינים ומחזקת את הלב! 🍅❤️"
  }
]
```

### שדות בכל פריט מזון:
- **icon**: האימוג'י של המזון (🍎, 🥕, 🍕)
- **name**: שם המזון בעברית
- **type**: "positive" (מזון בריא) או "negative" (מזון לצריכה מתונה)
- **title**: הכותרת שמופיעה כשלוחצים
- **description**: ההסבר המפורט למה המזון טוב/פחות טוב

## 🚀 איך להריץ?

### אופציה 1: דפדפן מקומי
1. פתח את הקובץ `index.html` ישירות בדפדפן
2. ⚠️ **שים לב**: יש לפתוח דרך שרת מקומי (לא file://)

### אופציה 2: Python Simple Server
```bash
cd fridge-project
python -m http.server 8000
```
פתח דפדפן ב: `http://localhost:8000`

### אופציה 3: Live Server (VS Code)
1. התקן את התוסף "Live Server" ב-VS Code
2. לחץ ימני על `index.html`
3. בחר "Open with Live Server"

## 🎨 מה האפליקציה מכילה?

### מדפים במקרר:
1. 🥗 **מדף ירקות וסלטים** - ברוקולי, גזר, סלט
2. 🍎 **מדף פירות** - תפוחים ועוד
3. 🥛 **מדף חלבונים ומוצרי חלב** - חלב, ביצים, דגים
4. 🍔 **מדף מזון מהיר** - פיצה, המבורגר, צ'יפס
5. 🍫 **מדף חטיפים ומשקאות** - שוקולד ועוד

### תכונות:
- ✨ אנימציות חלקות ומושכות
- 🎯 הסברים פשוטים ומתאימים לגיל
- 📱 מותאם למובייל וטאבלט
- 🌈 עיצוב צבעוני ומזמין

## 💡 טיפים לעריכה

### כדי לשנות תיאור קיים:
1. פתח את קובץ ה-JSON המתאים בתיקיית `food/`
2. מצא את המזון שאתה רוצה לערוך
3. ערוך את השדה `description`
4. שמור את הקובץ
5. רענן את הדפדפן - השינויים יופיעו מיד!

### כדי להוסיף מזון חדש:
1. פתח את קובץ ה-JSON המתאים
2. הוסף אובייקט חדש למערך (אל תשכח את הפסיק!)
3. מלא את כל השדות הנדרשים
4. שמור ורענן

### כדי להוסיף מדף חדש:
1. צור קובץ JSON חדש בתיקיית `food/`
2. הוסף את המדף ל-`fridgeStructure` ב-`app.js`:
```javascript
{
  id: "desserts",
  label: "🍰 מדף קינוחים",
  jsonFile: "desserts.json"
}
```

## 🐛 פתרון בעיות

**הדף לא טוען?**
- בדוק שקובץ ה-JSON תקין (אפשר לבדוק ב-jsonlint.com)
- וודא שפתחת דרך שרת (לא file://)
- בדוק את ה-Console בדפדפן לשגיאות

**תיאור לא מופיע?**
- בדוק שיש פסיקים בין אובייקטים
- וודא שכל השדות הנדרשים קיימים
- בדוק שהשם בעברית כתוב נכון

# המקרר הבריא שלי 🧊

פרויקט אינטראקטיבי לילדים ללימוד על תזונה בריאה.

## מבנה הפרויקט

```
fridge-project/
├── index.html          # קובץ HTML הראשי
├── style.css           # עיצוב CSS
├── app.js              # לוגיקה JavaScript (נתונים מוטמעים)
├── food/               # תיקיית מאכלים - קובץ JSON לכל מדף
│   ├── vegetables.json # ירקות וסלטים
│   ├── fruits.json     # פירות
│   ├── proteins.json   # חלבונים ומוצרי חלב
│   ├── fast-food.json  # מזון מהיר
│   └── snacks.json     # חטיפים ומשקאות
└── README.md           # תיעוד הפרויקט
```

## איך להשתמש

### דרך 1: פתיחה ישירה בדפדפן (מומלץ)
1. פתח את הקובץ `index.html` בדפדפן
2. הכל יעבוד מיד ללא הגדרות נוספות!
3. העבר את העכבר מעל כל מאכל לראות מידע בריאותי

### דרך 2: הרצה עם שרת מקומי (אופציונלי)
אם תרצה להשתמש בקבצי JSON דינמית, תצטרך שרת מקומי:

```bash
# Python 3
python -m http.server 8000

# או Node.js
npx http-server
```

ואז פתח: `http://localhost:8000`

## עריכת המאכלים

### אופציה 1: עריכה ב-app.js
הנתונים מוטמעים ב-`app.js` בתוך האובייקט `fridgeData`.
פשוט ערוך את הערכים שם.

### אופציה 2: עריכת קבצי JSON
כל מדף נמצא בקובץ נפרד בתיקיית `food/`:
- `vegetables.json` - ירקות
- `fruits.json` - פירות
- `proteins.json` - חלבונים
- `fast-food.json` - מזון מהיר
- `snacks.json` - חטיפים

כל מאכל מכיל:
```json
{
  "icon": "🥦",
  "name": "ברוקולי",
  "type": "positive",
  "title": "✓ למה ברוקולי טוב לי?",
  "description": "גורם לך להיות חזק!..."
}
```

## פתרון בעיית CORS

הפרויקט נבנה לעבוד **ללא שרת** - הנתונים מוטמעים ב-JavaScript.
קבצי ה-JSON מצורפים לצורך תיעוד ועריכה עתידית.

אם תרצה לטעון מ-JSON דינמית, תצטרך להריץ שרת מקומי (ראה למעלה).
